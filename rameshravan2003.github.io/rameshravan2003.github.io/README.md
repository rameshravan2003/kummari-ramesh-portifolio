# Ramesh Kummari: Cybersecurity Portfolio

Static site (HTML, CSS, a little vanilla JS). No build step.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish on GitHub Pages
1. Create a public repo named `rameshravan2003.github.io`.
2. Upload every file in this folder to the repo root (`index.html` must be at the top level).
3. Repo Settings, then Pages, then Deploy from a branch, then `main` and `/ (root)`. The site goes live at https://rameshravan2003.github.io.

## Placeholders to fill in

- "Lessons learned" for the Network Attack Simulation.
- Certificate files or URLs, if you want view buttons.
